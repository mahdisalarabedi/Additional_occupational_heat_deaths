# Additional_occupational_heat_deaths
Code and supporting materials for an analysis of additional occupational heat deaths in North Africa and the Middle East using GBD 2023 data.
# Reproducibility package

This repository contains the raw input data, analytical code, and supporting files required to reproduce the results reported in the manuscript:

**Heat deaths missing from occupational burden estimates in North Africa and the Middle East: an analysis of GBD 2023**

The package reproduces the results presented in Tables 1–3 and the numerical findings reported in the manuscript. It includes five input datasets, a Jupyter notebook documenting the analysis, and reference files for checking the reproduced results against the manuscript.

## Repository contents

| File or directory | Description |
|---|---|
| `reproduce_results.ipynb` | Main analytical notebook. It presents the analysis step by step, explains the equations described in the Methods section, and performs the calculations for all 21 countries. |
| `reproduce_results.html` | HTML version of the notebook, including its outputs. It can be viewed in a web browser without running Python. |
| `inputs/` | Contains the five raw input datasets in CSV format, used directly by the analytical notebook. Their contents are described below. |
| `inputs.xlsx` | Excel version of the same five datasets, with each dataset in a separate worksheet and an additional sheet describing the data. |
| `published_values.csv` and `published/` | Reference values reported in the manuscript, used by the notebook's final consistency checks. |
| `results/` | Output files generated by the notebook, including Tables 1–3, numerical results reported in the manuscript, comparisons with published values, and `results.xlsx`. |

## Input datasets

The five CSV files in `inputs/` contain the data used directly in the analysis. They consist of selected country- and region-level estimates from GBD 2023 and ILOSTAT.

| File | Description |
|---|---|
| `1_GBD_deaths_by_country_men.csv` | GBD deaths attributable to occupational risks and high temperature among men aged 15–64, by country, year, age group, and quantity. |
| `2_GBD_overlap_inputs_men.csv` | For causes shared by heat and occupational risks, occupational deaths and the corresponding heat-attributable fractions, by country, year, cause, and age group. These data are used to estimate the overlap between occupational and heat-attributable deaths. |
| `3_GBD_occupational_deaths_region_by_sex.csv` | GBD occupational-risk deaths for the NAME region, reported separately for men, women, and both sexes. |
| `4_ILO_employment_by_sector_modelled.csv` | ILO modelled employment estimates by country, year, sex, and economic sector, classified according to ISIC Revision 4. |
| `5_ILO_employment_to_population_ratio_men_modelled.csv` | ILO modelled employment-to-population ratios among men aged 15 and older, by country and year. |

The GBD input files include point estimates (`val`) and their corresponding 95% uncertainty intervals (`lower` and `upper`). The analysis uses the point estimates (`val`).

The study period is 2019–2023, with 1990 used as a comparison year. The ILO employment series for Sudan and Palestine end in 2022; therefore, their employment averages are calculated over 2019–2022.

## Reproducing the results

### Software requirements

The analysis was tested using Python 3.13, pandas 3.0, and SciPy 1.18.

The required Python packages and their versions are specified in `requirements.txt`.

### Running the analysis

1. Download or clone the repository.
2. Install the required packages using `requirements.txt`.
3. Open a terminal in the repository directory.
4. Execute the notebook using:

```bash
jupyter nbconvert --to notebook --execute reproduce_results.ipynb
```

Alternatively, open `reproduce_results.ipynb` in Jupyter Notebook or JupyterLab and run the cells sequentially.

The notebook executes in a few seconds under the tested environment and generates the analysis outputs in the `results/` directory.

## Analytical workflow

The notebook follows the analytical steps described in the manuscript's Methods section:

1. **Occupational and heat-attributable deaths (O and H):** Aggregation of occupational deaths across age groups and calculation of heat-attributable deaths, excluding deaths attributed to exposure to forces of nature.
2. **Overlap deaths (L):** Estimation of the overlap between occupational and heat-attributable deaths across shared causes and age groups.
3. **Descriptive results (Table 1):** Calculation of annual averages for 2019–2023 and comparison with 1990 estimates.
4. **Outdoor-sector employment (E):** Estimation of the proportion of men working in agriculture, forestry and fishing; mining and quarrying; and construction.
5. **Additional occupational heat deaths (Table 2):** Estimation of additional deaths and their contribution to the occupational burden under three relative-risk scenarios (RR = 1.5, 2, and 3).
6. **Relative-risk tipping points (Table 3):** Calculation of the relative risks required for additional occupational heat deaths to increase the estimated occupational burden by 5% and 10%.
7. **Additional manuscript results:** Reproduction of other numerical findings reported in the manuscript.
8. **Consistency checks:** Comparison of reproduced results with the values reported in the manuscript, covering 41 numerical checks and Tables 1–3.

## Using alternative input data

The input files in `inputs/` can be replaced with alternative datasets, provided that the replacement files retain the same column structure and variable names.

For example, users may substitute estimates from a later GBD release or alternative employment estimates and rerun the notebook. The final consistency-check step identifies differences between the newly calculated results and the values reported in the manuscript.
